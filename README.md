# Data-Cleaning-Reporting-Automation
Data Cleaning & Reporting Automation using Python and Power BI
 Project Overview
     This project focuses on automating the process of data cleaning and reporting using Python and Power BI.  
     The system cleans raw sales data by removing duplicates, handling missing values, and generating meaningful business insights through interactive dashboards.


 Objective
    - Automate data cleaning tasks
    - Remove duplicate records
    - Handle missing values
    - Generate cleaned datasets
    - Visualize sales insights using Power BI
    - Create automated reporting dashboards


 Technologies Used
    - Python
    - Pandas
    - Matplotlib
    - Power BI Desktop
    - CSV Files
    - VS Code


 Dataset
   dirty_sales_data.csv
    Contains raw sales data with:
        - Missing values
        - Duplicate records
        - Incomplete information

 cleaned_sales_data.csv
    Contains cleaned and processed data after automation.

 Project Workflow

   1. Data Collection
      Imported raw sales dataset in CSV format.
   2. Data Cleaning
      Using Python and Pandas:
      - Removed duplicate rows
      - Filled missing customer names
      - Filled missing city values
      - Replaced missing sales values with average sales

   3. Reporting Automation
      Generated cleaned dataset automatically.
   4. Data Visualization
        Created Power BI dashboard with:
        - KPI Cards
        - Bar Chart
        - Pie Chart
        - Line Chart
        - Interactive Filters


  Dashboard Visualizations
     KPI Cards
      - Total Sales
      - Total Customers
      - Average Sales

  Charts
    - Sales by City
    - Sales Distribution
    - Sales Trend Analysis

 Filters
    - City-wise slicer for interactive analysis

 Output
The project successfully:
    - Cleaned raw datasets
    - Removed duplicate records
    - Handled missing values
    - Generated automated reports
    - Built interactive Power BI dashboards
